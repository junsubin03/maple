## ⏱️ 반복 타이머 & 체크리스트

간단하게 사용할 수 있는 반복 타이머와 체크리스트 웹사이트입니다.

## 주요 기능

타이머
- 10초 ~ 10분 빠른 설정
- 타이머 실행 및 중지 및 설정한 시간으로 리셋 기능
- TTS 및 효과음 및 볼륨 조절 기능
- TTS 원하는 문장이나 대사를 입력해 음성으로 재생
- TTS / 효과음 복수 선택 기능

체크리스트
- 체크리스트 작성 및 관리
- 체크리스트 자동 저장
- 자정마다 체크 상태 자동 초기화
